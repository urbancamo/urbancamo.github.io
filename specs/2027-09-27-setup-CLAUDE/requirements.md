# Specification - Setup CLAUDE for Blog Writing

I want to create blog files from specifications. Help me setup CLAUDE.md so that the blog posts match my style,
use UK English and are difficult to distinguish from a style and length perspective from previous posts.

Analyse the projects and blog posts in this repository and create a set of heuristics that can be added to CLAUDE.md
to allow it to create the most compatible blog posts based on style, length and content.

When you've completed your analysis write the heuristics and any other information you require into a file in this 
directory called plan.md that gives detailed instructions that you can follow to update CLAUDE.md, for review first.
